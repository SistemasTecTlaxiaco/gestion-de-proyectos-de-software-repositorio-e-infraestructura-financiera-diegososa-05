# Sistema de Control y Comercialización de la Producción de Miel

**Organización Beneficiaria:** Unión de Productores de Miel de San Juan Ñumí, Oaxaca  
**Asignatura:** Gestión de Proyectos de Software  
**Estado del Proyecto:** Fase de Diseño y Planificación de Backlog  

---

## Descripción del Proyecto
Este repositorio alberga la documentación y el diseño del sistema de información para el control de apicultores, registros de cosechas, inventario de miel en bodega y comercialización para la **Unión de Productores de Miel de San Juan Ñumí, Oaxaca**. El objetivo es digitalizar los procesos operativos y establecer una planificación técnica que permita conectar el proyecto con oportunidades de financiamiento *on-chain*.
